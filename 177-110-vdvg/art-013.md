# Art. 13 3. Berechtigung
1 Die Unternehmensvertretung kann weitere Benutzerinnen und Benutzer zum Bezug von Dienstleistungen berechtigen.
2 Die Unternehmensvertretung ist für die Nachführung der berechtigten Benutzerinnen und Benutzer verantwortlich. Sie wird vom System regelmässig zur Überprüfung der erteilten Berechtigungen aufgefordert.
3 Das E-Konto der zum Bezug von Dienstleistungen berechtigten Benutzerinnen und Benutzer hat die für die Dienstleistung erforderliche Vertrauensstufe aufzuweisen.
