# Art. 50 Rechtsweg
1 Beschwerden gegen Semesternoten an Berufsfachschulen, die für die Lehrabschlussprüfungen übernommen werden, können innert zehn Tagen an das zuständige Gremium der Schule gerichtet werden. Dieses entscheidet endgültig.
2 Entscheide betreffend Nichtzulassung, Nichtpromotion und Nichtbestehen der Abschlussprüfungen können innert zehn Tagen mit Verwaltungsbeschwerde beim Departement angefochten werden.
3 Verfügungen von Anbietenden mit kantonalem Auftrag können mit Verwaltungsbeschwerde an das Departement weitergezogen werden.
