# Art. 4 Dauer der Amtsverhältnisse
1 Ständige Kommissionen werden auf eine Amtsperiode von vier Jahren gewählt. In besonderen Fällen können auch andere Kategorien von nebenamtlichen Mitarbeitenden auf eine Amtsperiode gewählt werden.
2 Neuwahlen innerhalb der Amtsperiode gelten für deren Rest.
3 Übrige nebenamtliche Mitarbeitende, die auf längere Dauer eine erweiterte Verwaltungsaufgabe erfüllen, werden auf unbefristete Zeit gewählt. Ist die Aufgabe vorübergehender Natur, erfolgt eine befristete Wahl.
